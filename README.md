# Power BI RFM Customer Segmentation Dashboard

## Project Overview

This project uses **Power BI** to analyze customer purchasing behavior using **RFM (Recency, Frequency, Monetary) analysis**.

The dashboard helps identify different customer segments based on their purchase recency, order frequency, and spending value.

## Dataset

The project uses a **Superstore sales dataset** containing information about:

* Customer details
* Order dates
* Sales and profit
* Products and categories
* Regions and locations
* Order and shipping information

## Key Analysis

### RFM Analysis

* **Recency** – How recently a customer made a purchase
* **Frequency** – How frequently a customer placed orders
* **Monetary** – How much a customer spent

Customers are scored on a **1–5 scale** and segmented into groups such as:

* Champions
* Loyal Customers
* Big Spenders
* At Risk
* Lost
* Others

## Dashboard Features

* Total Customers
* Total Sales
* Average Recency
* Average Frequency
* Average Monetary Value
* Customer segmentation
* Year-over-Year sales analysis
* Year-over-Year RFM metric comparison
* Customer and sales trends
* Interactive Power BI visualizations and filters
